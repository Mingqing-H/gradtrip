# 素材与许可

当前公共层使用内置 image_gen 生成的紫色双峰品牌与同源 favicon.png，以及 lucide-react 0.468.0 的具名图标（ISC License）。没有远程图片、远程字体或运行时素材接口。

当前 Design v3 使用透明三维小插画与 6 组摄影质感生成景观，均随站发布，详见 [v3 来源与提示词记录](./SOURCES-v3.md)。目的地保持稳定资源 ID 与 480/960 px 版本；当前最大单图 132.31 KiB（135490 bytes）。[T02 制作记录](./SOURCES-planning.md) 仅作为历史来源保留，源 PNG 不进入发布产物。

运行时依赖许可证：React / React DOM（MIT）、React Router（MIT）、Zod（MIT）、idb（ISC）、Lucide（ISC）。准确许可文本按 package-lock.json 对应版本从 node_modules 的 LICENSE 文件生成 public/THIRD_PARTY_NOTICES.txt。
