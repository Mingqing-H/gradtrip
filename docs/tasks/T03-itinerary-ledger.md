## 4. 必须交付

### 4.1 日程

- 按天列表、日期、起止时间、名称、类别、费用归属、人均预计活动支出、备注。
- 新增/修改/删除，上下移动，时间排序与手动顺序不冲突；跨午夜按规则拆分。
- 重叠提示、非法时间阻止保存、未知金额与明确零费用区分。
- included 仅记录已含费用，activities 参与活动分项替换；日程估算与实际支出互不自动改写。
- 首次生成不重复，重新确认默认保留，替换前展示影响并确认；超出新日期的活动保留、标识和可修正。
- 未确认时允许草稿日程；没有日期绑定时先设置允许范围，不能保存无法解释的活动日期。

### 4.2 费用与结算

- 每笔单垫付人、独立参与人选择；全员/部分参与的均摊、自定义金额及分配预览。
- 整数分处理，确定性尾差、金额总和校验；不参与人不承担，垫付人可不参与。
- 个人已付/应承担/已转出/已转入/当前余额，以及可展开来源。
- 确定性转账建议、部分金额记录、commandId 防重复，记录后重算余额与建议。
- 线下记录明确不等于支付或真实到账证明，不设置“全部付款成功”的假结果。
- 存在有效结算时禁止新增/改/删费用；提供撤销全部本地结算、修改费用、按真实转账重新登记的完整更正流程。
- 被撤销结算保留历史，不计入余额，不允许简单重新激活。

### 4.3 UI 与示例

- P03 桌面时间线与预算摘要、手机单列；P04 账目/结算视图、费用详情、分配与转账确认。
- 财务明细显示两位小数；应收/应付有文字，错误靠近金额和分配字段。
- 空账本、未知活动估算、已结算、操作锁定、保存失败均有可行动状态。
- 示例费用覆盖均摊、部分参与和自定义，支持 T01 注入稳定成员与日期。若示例成员 ID 改变，不能遗留失效引用。

## 5. 对外接口

- 页面：`ItineraryPage`、`LedgerPage`，通过各 feature 的 index.ts 导出。
- 本域统一入口导出 `applyItineraryLedgerCommand`、`validateItineraryLedgerTrip`，路径和签名在 B0 记录。
- 日程模块导出 `buildTemplateItinerary`、`getItineraryBudget`；模板输入为共享契约，个人基础估算显式作为参数或通过已注入规划接口获得。
- 财务模块导出 `getLedgerSummary`、`buildSettlementSuggestions`，不得隐式读取数据库。
- 提供 `createDemoLedger` 种子工厂供 T01 组合；构建过程不调用全局随机数或系统日期。
- 返回结构化业务错误，便于表单定位非法金额、成员、时间或结算锁。
