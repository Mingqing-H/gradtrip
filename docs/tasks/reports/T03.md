## 2. 业务规则落实

- **BR-08**：活动日期必须在绑定范围内（未绑定时先选范围）；起止同填同空/结束晚于开始；重叠仅提示（半开区间）；included 金额固定 null；`E'=E-A+S` 替换活动分项；重新确认默认保留、替换需显式命令与时间线预览；超范围活动保留并标记。
- **BR-09/BR-10**：金额以安全整数分处理；均摊尾差按 ID 升序；自定义逐人非负分且合计严格等于账单；未填写不自动补 0；保存最终分摊明细。
- **BR-11**：`B=P-O+已转出-已转入`；撤销结算不计余额；分摊和与余额和守恒校验；空账本为零不虚构数据。
- **BR-12**：确定性贪心建议；线下记录校验方向与金额、commandId 去重；有效结算锁定费用；撤销全部保留历史、不可重新激活，之后可更正费用并重登。
