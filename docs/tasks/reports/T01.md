### 接线规则（其他工作树合并 B0 后适用）

页面在对应 `src/features/*/index.ts` 导出 SquadPage / PlansPage / ItineraryPage / LedgerPage。分享集中面板导出名固定为 SharingPanels，另有 SnapshotPage / JoinPage / ResponsePage。外壳自动发现这些具名出口，不创建其他任务目录的占位文件。

领域签名统一：
```ts
(trip: Trip, payload: CommandPayload, context: CommandContext, dependencies: DomainDependencies) => Result<Trip>
(trip: Trip) => BusinessError[] // validator
```

handler 接收 payload 而非完整 Command，通过判别字段缩窄；不得更改 revision/updatedAt/appliedCommandIds，公共命令层统一管理。context={now,today,ids,commandId}，ID 由上层预分配，领域内不得随机生成。

- planning/index.ts：applyPlanningCommand、validatePlanningTrip、planningService（完整实现 PlanningService）。仍保留任务书要求的具名查询导出。
- itinerary/index.ts：buildTemplateItinerary，输入 {plan,template,ids}，返回 Result<Trip['itinerary']>。
- ledger/index.ts：applyItineraryLedgerCommand、validateItineraryLedgerTrip，统一覆盖日程/财务命令。
- sharing/index.ts：applySharingCommand、validateSharingTrip。
- 上述位置被 app/modules.ts 自动发现；缺失模块明确失败。check:integration 在全模块接入前应失败，不能作为 B0 已完成功能的证据。
- T02 createPlanningDemo 和 T03 createDemoLedger 的种子组合在下一阶段接入；暂不为其伪造示例。
- DestinationTemplate / TemplateActivity 形状在 services.ts。T02 确认时调用 dependencies.buildTemplateItinerary；T03/T04 通过 dependencies.planning 共享规则，不能交叉硬导入未合并的领域文件。

### 组件 API

`src/components/ui/index.tsx` 导出：
- Button：标准 button props + variant=primary/secondary/danger/ghost，默认 type=button。
- Input / Select：原生 props + 必需 label + 可选 error（就近呈现并连接 aria-describedby）。
- Dialog / Drawer：{open,title,onClose,children,footer?}；原生 modal 焦点限制、Escape 回调与关闭后焦点返回。
- Menu：{label,children}，原生 details/summary 披露，Escape 收起；内部按钮使用正常 Tab 顺序。
- Status：{status: SaveStatus}；ErrorNotice：{children}。
